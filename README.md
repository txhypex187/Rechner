# Rechner

Sparschwein mit Zinsrechner, als einzelne Webseite (`index.html`).

- **Stapel / Glas:** Münzen und Scheine antippen oder einen Betrag eintippen, auch mit Stückelung wie `1 € in 1 ct`.
- **Zinsen:** Zinsen pro Jahr, Monat und Tag (einfacher Jahreszins, Tag = Jahr ÷ 365).

Der Sparstand wird im Browser gespeichert (localStorage), also nur auf dem jeweiligen Gerät.
